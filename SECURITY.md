# Sensitive information

This public repository must not contain API keys, passwords, cookies, tokens, payment data, customer reference images or private application source.

Do not paste a suspected secret into a public Issue. If you accidentally expose one, revoke it with the provider immediately and remove it from the public material and history as appropriate. For a website account problem, use the site's support interface rather than publishing account details here.

Example settings contain no executable integration, credentials or production configuration.

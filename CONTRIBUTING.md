# Contributing

Use Issues for documentation errors and Pull Requests for focused tutorial or prompt improvements. Explain what changes and why. Prefer one task per contribution.

If you include an image, state how it was generated, whether it is an actual product run or an illustration, the relevant prompt and your right to share it. Never present examples as benchmarks without a documented test method. Do not include customer uploads, identifying account screenshots, credentials or private logs.

Keep links relevant to the tutorial. Advertising-only issues, unrelated directory links, unsupported model claims and copied proprietary source will not be accepted.

Before submitting, check Markdown links, image alt text and example provenance. This repository has no application build or paid API test requirement because it contains documentation only.

# Readable text in posters

Quote the exact text, explain hierarchy and placement, and keep the request short enough to proofread.

```text
Design a black and banana-yellow event poster. Exact large headline: "FRESH IDEAS" on two lines. Exact smaller subtitle: "CREATIVE NIGHT". Exact date: "24 OCTOBER". Keep the three text blocks distinct, aligned and fully visible. Add one sculptural folded yellow fabric ribbon as the image. No other words, logo or watermark.
```

## Workflow

1. Start with a few words; describe placement and clear space.
2. Choose a shape appropriate to the intended layout.
3. Generate one result and inspect every character at full resolution.
4. Check spelling, punctuation, repeated words, alignment and crop margins.
5. For production-critical text, add or correct typography in a conventional design editor instead of repeatedly hoping for exact letters.

See [original poster](../examples/04-exact-text/README.md). The visible example text is not a real event announcement. Text rendering accuracy varies; no perfect-typography claim is made.

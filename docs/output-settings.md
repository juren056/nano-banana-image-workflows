# Aspect ratio, resolution and output count

Choose settings for the final destination before generating.

| Destination | Useful starting ratio | Review |
| --- | --- | --- |
| Product card or square post | 1:1 | Keep labels and product edges away from the crop |
| Story or portrait composition | 9:16 | Leave room for overlays above and below the subject |
| Wide cover or landscape frame | 16:9 | Keep important details inside the central safe area |
| Example artwork in this repository | 3:2 | This is an asset layout, not proof of a model setting |

Available ratios and resolutions depend on the selected model. Do not assume every model supports 4K or editing. Start with the lowest supported resolution that lets you inspect the concept, then review the current higher-resolution quote if needed.

Output count multiplies work and may multiply the charge. Always use the website's **total** quote rather than multiplying a remembered base price. This repository does not freeze prices or override server validation.

Check export dimensions and actual file format. A larger file is not proof of more accurate text, better product fidelity or a sharper source reference.

中文要点：按发布位置选比例，检查所选模型支持的分辨率与总报价。数量、分辨率可能改变费用，不能用旧价格推算当前实际扣费。

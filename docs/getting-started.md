# Getting started

Use this repository as a workflow guide, not a promise about a specific model's output.

## Start with the operation

- **Text to image:** create a new image from a written description.
- **Reference editing:** upload a source image and describe the change plus the details to preserve.
- **Character scenes:** reuse a source-only character reference for each separate scene.
- **Exact-text artwork:** quote the words and state their location and hierarchy.

A practical brief names **subject + setting + composition + lighting + exact text + details to preserve**. Only include the parts that matter to your task.

## Run one deliberate request

1. Open the website's generator, choose Text to image or Image to image, and select a compatible available model.
2. Paste a recipe or write your own prompt. Attach only references you own or are permitted to use.
3. Choose an aspect ratio and supported resolution; start with one output to inspect the first result.
4. Review the total credit quote and account balance. Website generation is a paid operation when submitted; documentation and prompt copying are free to read.
5. Submit only when you are ready. Inspect the result before downloading, publishing or requesting a variation.

## Review before iterating

Check shape, spelling, anatomy, identity, product accuracy, light direction and safe margins. Change one requirement at a time so you can tell what improved. Keep an original reference beside your result.

Settings examples are recommendations. They do not bypass the website's model compatibility, authentication, content checks, credit pricing or provider rules. If a task fails, read the actual status and credit history rather than repeatedly submitting it.

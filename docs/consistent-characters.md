# Consistent fictional characters across scenes

## Keep a stable reference

Choose one clear, source-only portrait or scene. Use the same reference for each generation rather than feeding successive outputs back into the next request, which can compound identity drift.

```text
Use the uploaded fictional adult photographer as the character reference. Preserve his face, short swept dark hair, charcoal overshirt, cream T-shirt and mustard camera strap. Place him waist-up inside a small bookshop browsing a shelf. Natural window light, realistic anatomy, visible face and hands. Do not add another person or text.
```

Generate the studio, street and bookshop as separate scenes if individual frames are the goal. Change the action and setting while keeping the identity description stable.

## Review checklist

Compare face shape, hairline, apparent age, clothing color and fit, camera details and hand anatomy. Do not assume a repeated written name guarantees the same face. Use the [source-only photographer](../assets/examples/photographer-source.webp), not the three-panel sheet.

The fictional contact sheet is an illustrative asset, not a measured consistency test. Use real-person references only with appropriate permission. See [example](../examples/03-character-scenes/README.md).
